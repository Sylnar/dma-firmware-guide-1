Sylnar Tool for FPGA DMA board management

Sylnar Tool is a standalone Windows 10/11 application for FPGA DMA board detection, DNA reading, firmware flashing, driver installation, and DMA speed testing. No Vivado installation is required.

Install and detect

Download Sylnar.exe from the official latest GitHub release and run it as Administrator on the second PC. Install the CH347 driver for JTAG and the FT601 driver for DMA data from the Drivers tab.

Connect the board over USB and select Detect Board. The application reports the device name, IDCODE, and Device DNA. Copy the DNA when a board-specific firmware build is required.

Flash and verify

Select the correct .bin firmware for persistent SPI flash or a .bit file for volatile SRAM. Wait for sector erase, write, and verify to complete. Power cycle the target PC after a successful flash.

Sylnar Tool supports detection and flashing across Artix-7 boards. Kintex-7 boards can be detected but cannot be SPI flashed. SylnarCore firmware compatibility is a separate check, currently XC7A75T and XC7A100T board classes.

Current documentation and downloads

The Sylnar Tool product page links the official releases and current quick-start instructions. Existing installations also check for updates automatically on launch.
