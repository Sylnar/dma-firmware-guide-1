Second-PC DMA setup checklist

Sylnar CS2 and Wardogs use a second Windows PC for DMA hardware access and tooling. Prepare the hardware path and validate compatibility before buying firmware or a subscription.

Required hardware

  • A second Windows PC with a spare PCIe slot
  • A supported Artix-7 DMA capture card
  • A Makcu input device
  • A monitor or capture path for the second machine

The gaming PC remains dedicated to the game. The second PC runs the Sylnar tooling and communicates with the DMA board.

Validate BIOS and board compatibility

Check IOMMU or VT-d / AMD-Vi, Kernel DMA Protection, PCIe ACS, Above 4G Decoding, Resizable BAR, ASPM, BIOS version, and slot lane sharing. Newer X670, X870, X870E, Z790, and Z890 boards may need additional review, but strict defaults do not automatically mean incompatibility.

Use Sylnar Tool to install CH347 and FT601 drivers, detect the board, and copy Device DNA. Then submit the compatibility checklist.
