# PCIe DMA Firmware Engineering Guide - Version 2

**[Download the guide (PDF)](Sylnar_DMA_Firmware_Guide_v2.pdf?raw=true)**

**Edition:** 2.2, revised 14 November 2026. **50 pages.**

A practical guide to creating Artix-7 PCIe firmware and implementing a reference
device's documented interface. Includes:

- Donor selection, exact function identification and capture planning.
- Windows inspection and Linux text/binary configuration dumps with manifests.
- Repeated-state comparison, capability checks, BAR analysis and register workbooks.
- Reviewed-reset-image conversion, COE export and byte-order verification.
- Step-by-step public-project setup, HDL integration, simulation and Vivado builds.
- Register, interrupt, reset, descriptor and command-completion behavior.
- A public class-interface example, filesystem checks and persistence validation.
- Board-specific programming, host verification, troubleshooting and release checks.

Complete teaching code is printed in the PDF. Save the listings as local files
when following the workshops; this repository contains only the PDF and README.
