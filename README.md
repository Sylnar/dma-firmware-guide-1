# PCIe DMA Firmware Engineering Guide - Version 2

**[Download the guide (PDF)](Sylnar_DMA_Firmware_Guide_v2.pdf?raw=true)**

A step-by-step guide to creating Artix-7 PCIe firmware and emulating a device.
Includes source setup, reference-device analysis, register implementation,
self-checking simulation, Vivado builds, programming and host verification.
Complete example code is printed in the PDF; save the listings as local files
when following the labs.

**Edition:** 2.1, revised 14 November 2026.

**[Join the Sylnar Discord](https://discord.gg/sylnar)** for guide questions and support.

The HDL example passed 56 checks in Vivado Simulator 2022.2. Full-board and
physical hardware acceptance are not claimed. The original disclaimer and
distribution terms remain attached to the PDF.
